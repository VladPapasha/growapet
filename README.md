# Grow a Pet — запуск

Игра состоит из одного сервера. Он сразу и отдаёт игру, и работает ботом, и принимает оплату звёздами. Всё бесплатно:

| Что | Где | Зачем |
|---|---|---|
| Код | GitHub | отсюда хостинг берёт файлы |
| База данных | Neon | хранит прогресс игроков, покупки, друзей |
| Сервер | Render | запускает игру и бота |
| Реклама | AdsGram | платит тебе за просмотры рекламы |

Займёт примерно 30–40 минут. Всё делается в браузере, ничего устанавливать не нужно.

---

## Шаг 0. Новый токен бота (обязательно)

Старый токен засветился на скриншоте — его надо заменить.
@BotFather → `/mybots` → твой бот → **API Token** → **Revoke current token**. Скопируй новый токен и никому его не показывай.

## Шаг 1. Загрузи код на GitHub

1. github.com → **+** → **New repository** → имя `growapet` → **Private** → **Create repository**.
2. Нажми **uploading an existing file** и перетащи **всё содержимое** папки игры: `server.js`, `package.json`, `.gitignore`, `README.md` и папку `public` целиком (вместе с `pets`).
3. **Commit changes**.

## Шаг 2. База данных Neon

1. neon.tech → **Sign up** (можно через GitHub).
2. Создай проект: имя `growapet`, регион **Europe (Frankfurt)**.
3. На главной проекта нажми **Connect** и скопируй строку подключения. Она выглядит так:
   `postgresql://user:пароль@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`

Таблицы сервер создаст сам.

## Шаг 3. Сервер на Render

1. render.com → **Sign up** через GitHub.
2. **New +** → **Web Service** → выбери репозиторий `growapet`.
3. Настройки:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Instance Type**: **Free**
4. Ниже **Environment Variables** → добавь:

| Ключ | Значение |
|---|---|
| `BOT_TOKEN` | новый токен из шага 0 |
| `DATABASE_URL` | строка из Neon |
| `WEBAPP_URL` | пока поставь `https://example.com`, заменишь в пункте 6 |
| `SUPPORT` | твой контакт для вопросов по покупкам, например `@твой_ник` |
| `ADMIN_ID` | твой Telegram ID (узнать: напиши боту @userinfobot) |

5. **Create Web Service**. Подожди, пока появится **Live**.
6. Вверху страницы будет адрес вида `https://growapet-xxxx.onrender.com`. Скопируй его, открой **Environment**, впиши в `WEBAPP_URL` и сохрани. Render перезапустит сервер.
7. Открой в логах (**Logs**): должна быть строка `Бот @petgraderbot подключён`.

Сервер сам поставит боту кнопку «Играть», команды и вебхук.

## Шаг 4. Mini App в BotFather (для реферальных ссылок)

@BotFather → `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → вставь адрес из шага 3.6.
Без этого ссылки-приглашения вида `t.me/бот?startapp=...` не откроют игру.

Старая игра на GitHub Pages больше не нужна. Прогресс тестовых игроков туда не переносится, на сервере все начинают заново.

## Шаг 5. Чтобы сервер не засыпал

Бесплатный Render засыпает после 15 минут без игроков, и потом первый запуск ждёт около минуты.
Исправляется бесплатно: cron-job.org → **Create cronjob** → URL `https://твой-адрес.onrender.com/health` → **каждые 10 минут** → сохранить.

## Шаг 6. Реклама AdsGram

1. partner.adsgram.ai → зарегистрируйся → добавь приложение (ссылка на бота).
2. Создай блок формата **Rewarded** (реклама за награду). Скопируй **blockId** (число).
3. На Render в **Environment** добавь `ADSGRAM_BLOCK_ID` = blockId → сохрани.

После модерации AdsGram в игре появятся кнопки «📺 Смотреть»: монеты в магазине, бесплатное яйцо и x2 к офлайн-доходу. Лимит — 25 просмотров в день, не чаще раза в 30 секунд.

## Оплата звёздами

Настраивать ничего не нужно, Telegram Stars работают сразу.
- Купленное выдаётся автоматически, повторный платёж одного чека не засчитывается.
- Деньги: BotFather → бот → **Balance**. Звёзды можно вывести в **TON** через Fragment (Telegram держит их около 21 дня).
- Возврат: напиши боту `/refund <id платежа>` со своего аккаунта (ADMIN_ID). Id есть в чеке у покупателя.
- Крипту напрямую за игровые покупки Telegram брать запрещает: цифровые товары в ботах продаются только за звёзды.

## Админка

В игре: ⚙️ Настройки → **🛠 Админка**. Кнопку видит только аккаунт, чей Telegram ID записан в `ADMIN_ID` на Render (узнать свой ID — бот @userinfobot). Сервер ещё раз проверяет ID на каждой команде.

Что умеет:
- статистика: игроки, активные за сутки, покупки и сколько звёзд заработано;
- найти игрока по ID и посмотреть его баланс, доход, петов;
- выдать или списать монеты, сделать баланс любым числом;
- выдать любого пета (включая золотых и радужных) и билеты на яйца;
- удача 0–100%: проигрыш в слотах, рулетке, апгрейде, яйцах и ракетке перекручивается с этой вероятностью;
- полная энергия, сброс прогресса игрока.

Не снимай рекламу игры на аккаунте с включённой удачей: игроки будут ждать таких же выигрышей, а за обман в рекламе Telegram может заблокировать бота.

## Как менять игру

Всё про баланс лежит в `public/core.js`: петы, цены, шансы яиц, апгрейдер (`UPG`), награды, задания, товары за звёзды (`PRODUCTS`).
Поменял файл на GitHub → Render сам пересоберёт сервер за пару минут.

**Новый фото-пет:** положи квадратную картинку в `public/pets/`, например `bob.jpg`, и добавь строку в `PETS`:
```js
{ id: 'm_bob', img: 'pets/bob.jpg', name: 'Боб', r: 2, v: 40000, fam: 'meme' },
```
`r` — редкость (0 обычный … 4 мифический), `v` — цена, `fam: 'meme'` — выпадает из мем-яйца.

## Если что-то не работает

- **Игра пишет «Сервер просыпается»** — подожди минуту, или настрой шаг 5.
- **«Не получилось войти»** — проверь, что `BOT_TOKEN` на Render совпадает с текущим токеном бота.
- **Бот молчит** — открой Logs на Render и посмотри ошибку; чаще всего неверный `WEBAPP_URL` (должен начинаться с `https://` и без `/` в конце).
- **Покупка не пришла** — подожди 10–20 секунд и переоткрой игру; если нет — смотри Logs.
